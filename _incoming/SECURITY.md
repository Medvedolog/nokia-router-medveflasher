# Security and data handling

Generated backups may contain MAC addresses, ONU identifiers, serial numbers,
credentials, provisioning data and ISP-specific calibration. Do not attach raw
MTD dumps, `bosa.bin`, `ri.bin`, `config`, `romfile`, `all_flash`, or full
U-Boot environments to public issues.

When reporting a problem, provide sanitized command output, image hashes,
partition names and sizes. Remove credentials and device-specific identifiers.
